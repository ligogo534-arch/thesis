# Research Purpose

Computational text analysis of Chinese readers' reception of four works by Ueno Chizuko on Douban.

## Methods

- Text preprocessing and descriptive statistics
- BERTopic topic modeling
- Dictionary-based sentiment analysis
- LLM-based aspect-based sentiment analysis (ABSA)
- Robustness and reliability checks

## Repository Structure

- `thesis_douban_analysis/`: Analysis code and related materials

## Data Availability and Privacy

Raw Douban comments and personal user information are not included in this repository.
